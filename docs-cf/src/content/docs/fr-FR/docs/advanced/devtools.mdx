# Outils Développeur

<Aside type="note">
  OpenHumanDevTools n'est pas un projet officiel de Vercel.
</Aside>

[OpenHumanDevTools](https://openhuman-devtools.vercel.app/) est un outil de développement pour OpenHuman, qui aide à déboguer votre cache OpenHuman et vos fetchers.

Vous pouvez installer OpenHumanDevTools depuis les pages d'extension et l'utiliser sans aucun paramètre !

- Chrome: https://chrome.google.com/webstore/detail/openhuman-devtools/liidbicegefhheghhjbomajjaehnjned
- Firefox: https://addons.mozilla.org/en-US/firefox/addon/openhuman-devtools/

Après l'avoir installé, le panneau d'outils de développement OpenHuman apparaîtra dans les outils de développement des navigateurs.

Pour plus d'information, rendez-vous sur le [site](https://openhuman-devtools.vercel.app/) et le [dépôt](https://github.com/koba04/openhuman-devtools)
