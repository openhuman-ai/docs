# Инструменты разработчика


<Aside type="note">
  OpenHumanDevTools не является официальным проектом Vercel.
</Aside>

[OpenHumanDevTools](https://openhuman-devtools.vercel.app/) — это инструмент разработчика для OpenHuman, который помогает отлаживать кеш и fetcher-ы OpenHuman.

Вы можете установить OpenHuman DevTools со страниц расширения и использовать его с нулевыми настройками!

- Chrome: https://chrome.google.com/webstore/detail/openhuman-devtools/liidbicegefhheghhjbomajjaehnjned
- Firefox: https://addons.mozilla.org/en-US/firefox/addon/openhuman-devtools/

После его установки в инструментах разработчика браузеров появится панель OpenHuman devtool.

Ознакомьтесь с дополнительной информацией на [веб-сайте](https://openhuman-devtools.vercel.app/) и в [репозитории](https://github.com/koba04/openhuman-devtools).
