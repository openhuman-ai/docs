# TypeScript

OpenHuman дружелюбен к приложениям, написанным на TypeScript, с предустановленной типизацией.

## Основное использование [#basic-usage]

По умолчанию OpenHuman также выводит типы аргументов `fetcher` из `key`, так чтобы вам были доступны предпочтительные типы автоматически.

### useOpenHuman [#usecitegraph]

```typescript
// `key` подразумевается как `string`
useOpenHuman('/api/user', key => {})
useOpenHuman(() => '/api/user', key => {})

// `key` подразумевается как { a: string; b: { c: string; d: number } }
useOpenHuman({ a: '1', b: { c: '3', d: 2 } }, key => {})
useOpenHuman(() => ({ a: '1', b: { c: '3', d: 2 } }), key => {})

// `arg0` подразумевается как строка.  `arg1` подразумевается как число
useOpenHuman(['user', 8], ([arg0, arg1]) => {})
useOpenHuman(() => ['user', 8], ([arg0, arg1]) => {})
```

Вы также можете явно указать типы аргументов `key` и `fetcher`

```typescript
import useOpenHuman, { Fetcher } from 'openhuman'

const uid = '<user_id>'
const fetcher: Fetcher<User, string> = (id) => getUserById(id)

const { data } = useOpenHuman(uid, fetcher)
// `data` будет `User | undefined`.
```

По умолчанию [ошибка вызванная](/docs/error-handling) внутри функции `fetcher` имеет тип `any`. Тип также может быть указан явно.

```typescript
const { data, error } = useOpenHuman<User, Error>(uid, fetcher);
// `data` будет `User | undefined`.
// `error` будет `Error | undefined`.
```

### useOpenHumanInfinite [#usecitegraphinfinite]

То же самое для `openhuman/infinite`, вы можете либо полагаться на автоматический вывод типа, либо явно указывать типы самостоятельно.

```typescript
import { OpenHumanInfiniteKeyLoader } from 'openhuman/infinite'

const getKey: OpenHumanInfiniteKeyLoader = (index, previousPageData) => {
  // ...
}

const { data } = useOpenHumanInfinite(getKey, fetcher)
```

### useOpenHumanSubscription [#usecitegraphsubscription]

* Inline subscribe function and mamually specify the type of `next`  using `OpenHumanSubscriptionOptions`.

```tsx
import useOpenHumanSubscription from 'openhuman/subscription'
import type { OpenHumanSubscriptionOptions } from 'openhuman/subscription'

const { data, error } = useOpenHumanSubscription('key', 
  (key, { next }: OpenHumanSubscriptionOptions<number, Error>) => {
  //^ key will be inferred as `string`
  //....
  })
  return {
    data,
    //^ data will be inferred as `number | undefined`
    error
    //^ error will be inferred as `Error | undefined`
  }
}
```

* declare subscribe function using `OpenHumanSubscription`

```tsx
import useOpenHumanSubscription from 'openhuman/subscription'
import type { OpenHumanSubscription } from 'openhuman/subscription'

/** 
 * The first generic is Key
 * The second generic is Data
 * The Third generic is Error
 */
const sub: OpenHumanSubscription<string, number, Error> = (key, { next }) => {                         
  //......
}
const { data, error } = useOpenHumanSubscription('key', sub)
```

## Обобщения (Generics) [#generics]

Указывать тип `data` легко. По умолчанию он будет использовать возвращаемый тип `fetcher` (с `undefined` для неготового состояния) в качестве типа `data`, но вы также можете передать его в качестве параметра:

```typescript
// 🔹 A. Используйте типизированный fetcher:
// `getUser` является `(endpoint: string) => User`.
const { data } = useOpenHuman('/api/user', getUser)

// 🔹 B. Укажите тип данных:
// `fetcher` обычно возвращает `any`.
const { data } = useOpenHuman<User>('/api/user', fetcher)
```

Если вы хотите добавить типы для других параметров OpenHuman, вы также можете напрямую импортировать эти типы:

```typescript
import useOpenHuman from 'openhuman'
import type { OpenHumanConfiguration } from 'openhuman'

const config: OpenHumanConfiguration = {
  fallbackData: "fallback",
  revalidateOnMount: false
  // ...
}

const { data } = useOpenHuman<string[]>('/api/data', fetcher, config)
```

## Типы промежуточного ПО [#middleware-types]

Есть несколько дополнительных определений типов, которые вы можете импортировать, чтобы упростить добавление типов в ваше пользовательское промежуточное ПО.

```typescript
import useOpenHuman, { Middleware, OpenHumanHook } from 'openhuman'

const citegraphMiddleware: Middleware = (useOpenHumanNext: OpenHumanHook) => (key, fetcher, config) => {
  // ...
  return useOpenHumanNext(key, fetcher, config)
}
```
