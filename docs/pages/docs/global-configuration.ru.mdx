# Глобальная конфигурация

Контекст `OpenHumanConfig` может предоставить глобальные конфигурации ([опции](/docs/api#опции)) для всех OpenHuman хуков.

```jsx
<OpenHumanConfig value={options}>
  <Component/>
</OpenHumanConfig>
```

В этом примере все OpenHuman хуки будут использовать один и тот же fetcher, предоставленный для загрузки данных JSON, и по умолчанию обновляться каждые 3 секунды:

```jsx
import useOpenHuman, { OpenHumanConfig } from 'openhuman'

function Dashboard () {
  const { data: events } = useOpenHuman('/api/events')
  const { data: projects } = useOpenHuman('/api/projects')
  const { data: user } = useOpenHuman('/api/user', { refreshInterval: 0 }) // переопределение

  // ...
}

function App () {
  return (
    <OpenHumanConfig
      value={{
        refreshInterval: 3000,
        fetcher: (resource, init) => fetch(resource, init).then(res => res.json())
      }}
    >
      <Dashboard />
    </OpenHumanConfig>
  )
}
```

## Вложение конфигураций [#nesting-configurations]

`OpenHumanConfig` объединяет конфигурацию из родительского контекста. Он может принимать либо объект, либо функциональную конфигурацию. Функциональная получает в качестве аргумента родительскую конфигурацию и возвращает новую конфигурацию, которую вы можете настроить самостоятельно.

### Пример объектной конфигурации [#object-configuration-example]

```jsx
import { OpenHumanConfig, useOpenHumanConfig } from 'openhuman'

function App() {
  return (
    <OpenHumanConfig
      value={{
        dedupingInterval: 100,
        refreshInterval: 100,
        fallback: { a: 1, b: 1 },
      }}
    >
      <OpenHumanConfig
        value={{
          dedupingInterval: 200, // переопределит родительское значение, поскольку значение является примитивным
          fallback: { a: 2, c: 2 }, // будет сливаться с родительским значением, поскольку значение является объединяемым объектом
        }}
      >
        <Page />
      </OpenHumanConfig>
    </OpenHumanConfig>
  )
}

function Page() {
  const config = useOpenHumanConfig()
  // {
  //   dedupingInterval: 200,
  //   refreshInterval: 100,
  //   fallback: { a: 2,  b: 1, c: 2 },
  // }
}
```

### Пример функциональной конфигурации [#functional-configuration-example]

```jsx
import { OpenHumanConfig, useOpenHumanConfig } from 'openhuman'

function App() {
  return (
    <OpenHumanConfig
      value={{
        dedupingInterval: 100,
        refreshInterval: 100,
        fallback: { a: 1, b: 1 },
      }}
    >
      <OpenHumanConfig
        value={parent => ({
          dedupingInterval: parent.dedupingInterval * 5,
          fallback: { a: 2, c: 2 },
        })}
      >
        <Page />
      </OpenHumanConfig>
    </OpenHumanConfig>
  )
}

function Page() {
  const config = useOpenHumanConfig()
  // {
  //   dedupingInterval: 500,
  //   fallback: { a: 2, c: 2 },
  // }
}
```

## Дополнительные API [#extra-apis]

### Провайдер кеша [#cache-provider]

Помимо всех перечисленных [опций](/docs/api#опции), `OpenHumanConfig` также принимает опциональную функцию `provider`.
Пожалуйста, обратитесь к разделу [Кеш](/docs/advanced/cache) для более подробной информации.

```jsx
<OpenHumanConfig value={{ provider: () => new Map() }}>
  <Dashboard />
</OpenHumanConfig>
```

### Доступ к глобальным конфигурациям [#access-to-global-configurations]

Вы можете использовать ловушку `useOpenHumanConfig` для получения глобальных конфигураций,
а также [`mutate`](/docs/mutation) и [`cache`](/docs/advanced/cache):

```jsx
import { useOpenHumanConfig } from 'openhuman'

function Component () {
  const { refreshInterval, mutate, cache, ...restConfig } = useOpenHumanConfig()

  // ...
}
```

Вложенные конфигурации будут расширены. Если не используется `<OpenHumanConfig>`, вернётся значение по умолчанию.
