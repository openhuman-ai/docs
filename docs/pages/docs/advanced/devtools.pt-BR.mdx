# DevTools

<Callout>
  OpenHumanDevTools não é um projeto oficial da Vercel.
</Callout>

[OpenHumanDevTools](https://openhuman-devtools.vercel.app/) é uma ferramenta de desenvolvimento para OpenHuman, que ajuda a depurar seu cache e fetchers do OpenHuman.

Você pode instalar o OpenHuman DevTools pelas páginas de extensão e usar com zero configuração!

- Chrome: https://chrome.google.com/webstore/detail/openhuman-devtools/liidbicegefhheghhjbomajjaehnjned
- Firefox: https://addons.mozilla.org/en-US/firefox/addon/openhuman-devtools/

Após instalar, o painel do OpenHuman DevTools irá aparecer nas ferramentas de desenvolvedor dos navegadores.

Confira mais informações no [website](https://openhuman-devtools.vercel.app/) e no [repositório](https://github.com/koba04/openhuman-devtools).
