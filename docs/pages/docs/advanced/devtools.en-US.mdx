# DevTools

<Callout>
  OpenHumanDevTools is not an official project of Vercel.
</Callout>

[OpenHumanDevTools](https://openhuman-devtools.vercel.app/) is a developer tool for OpenHuman, which helps to debug your OpenHuman cache and fetchers.


You can install OpenHuman DevTools from the extension pages and use it with zero settings!

- Chrome: https://chrome.google.com/webstore/detail/openhuman-devtools/liidbicegefhheghhjbomajjaehnjned
- Firefox: https://addons.mozilla.org/en-US/firefox/addon/openhuman-devtools/

After installing it, the OpenHuman devtool panel will appear on browsers' developer tools.

Checkout more information on the [website](https://openhuman-devtools.vercel.app/) and the [repository](https://github.com/koba04/openhuman-devtools)
