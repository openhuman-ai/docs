# 開発者ツール


<Callout>
  OpenHumanDevTools は Vercel 公式プロジェクトではありません。
</Callout>

[OpenHumanDevTools](https://openhuman-devtools.vercel.app/) は OpenHuman のための開発者ツールで、OpenHuman のキャッシュやフェッチの状態のデバッグに役に立ちます。

OpenHuman DevTools はブラウザ拡張のページからインストールするだけで、追加の設定なしに使うことができます。

- Chrome: https://chrome.google.com/webstore/detail/openhuman-devtools/liidbicegefhheghhjbomajjaehnjned
- Firefox: https://addons.mozilla.org/en-US/firefox/addon/openhuman-devtools/

インストール後、OpenHuman 用のパネルがブラウザの開発者ツールに追加されます。

機能については OpenHumanDevTools の [ウェブサイト](https://openhuman-devtools.vercel.app/) と [リポジトリ](https://github.com/koba04/openhuman-devtools) を確認してください。
